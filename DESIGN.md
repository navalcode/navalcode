# GitHub profile: evidence before decoration

GitHub owns the page chrome, fonts, themes and layout. The profile uses native Markdown headings and open project entries so the technical copy remains searchable, selectable and legible at narrow widths. It does not try to embed a second website inside the profile.

The opening gives identity, engineering focus and two reading paths. Two200px app captures wrap naturally onto separate lines in a narrow content area. They show actual Android emulator output, not generated devices, stock photos or physical-device evidence. Both images link to the implementation; descriptive alt text and a nearby caption explain their source, English UI and fictional data. The photographs invented by the design reference are not used: Rumbo renders original Canvas landscapes.

Open project entries replace the three-column comparison table to reduce horizontal reading on mobile. Their order stays aligned across English/Spanish. Substantive architecture, concurrency, integration, testing, AI/SDD and attribution remain in the profile. iOS stays a roadmap until a runnable implementation and platform evidence exist. No fake statistics, testimonials, experience duration or store claims are added.

The warm paper/ink/copper palette and Outfit/Fraunces remain visible in the actual app images and the linked personal site. GitHub's own text colors and fonts are inherited; there is no custom script, tracking widget or animation. Source and images are exported explicitly, separately from local coordination/research.
